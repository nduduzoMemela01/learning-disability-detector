# Learning Disability Detector

## Project Overview
A web based application designed to help identify and classify learning disabilities based on user input. The system provides a simple interface for users to answer a series of questions or submit data, which is then processed to provide a preliminary indication of potential learning challenges.

## Tech Stack
*   **Backend:** Python, Flask
*   **Database:** SQLite
*   **Frontend:** HTML, CSS
*   **Tools:** Git, GitHub

## Features
*   User friendly web interface.
*   Secure user login and data storage using SQLite.
*   Automated logic to process input and generate results.

## How to Run
1. Clone the repository.
2. Install the required libraries (see `libraries used`).
3. Run `python app.py` in your terminal.
4. Open your browser and navigate to `http://localhost:5000`.
